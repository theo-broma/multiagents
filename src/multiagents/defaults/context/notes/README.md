# User notes

Write free-form Markdown notes here. This directory belongs to the user;
agents never edit, move or delete its contents. The initializer reads every
note at the start of each session and records its path, raw-byte SHA-256 hash
and disposition in a plan's Notes considered section. Editing a note makes it
unprocessed again. The orchestrator acts only through plans, never directly
on notes. This README is excluded from note counts.
