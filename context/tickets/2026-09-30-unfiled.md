## A pinned start can never pass a lapsed breaker's half-open trial (found 2026-09-30 by researcher ag-66d61b)

- **What happens.** A pinned start runs `_pin_health()` (runner.py ~2052), which calls `_half_open()` and claims the trial by writing `trial_at`. The same start's routing then calls `_half_open()` a second time (~2072–2084). That call sees its own fresh `trial_at`, refuses, and sets a local `cooldown_until` of now+60.
- **The result.** The start is refused with "exhausted or cooling down" although the budget is usable. Every later pinned attempt repeats the cycle, so a tripped provider can never be reached through a pin.
- **Workaround used.** `Tree.note_run_outcome('agy', True)`, applied because the agy reading was healthy at 0.83.
- **Fix.** In-house: the routing pass must recognise the trial its own start already claimed. It overlaps the M round-3 area of runner.py start(), so schedule it after ag-074735 merges.

## A stop during launch leaves `setsid` children running (found 2026-09-30 by ag-2caa66, TS Run A)

- **The race.** `agentwrap` starts the agent before it writes `container.pid`. A stop that lands in that gap reads no agent pid, so `DockerExecutor.kill_detached` never reaches the `setsid` child, and it keeps running.
- **Where.** `agentwrap.main` and `DockerExecutor.kill_detached`. The reproduction, a 1 s delay before the pid write, is in context/ts/manifests/README.md on branch agents/implementer-deep/2caa66.
- **Fix options:**
  - the kill script reads and waits for the pid file inside the container;
  - or the wrapper walks the agent's process tree when it forwards a signal.
- **It needs its own test.** The sg_r7 test now waits for `container.pid` first.

## No operator path to clear an unidentifiable cleanup hold (2026-10-01, opus ag-cc25b3)

- **The case.** A durable `cleanup_hold` whose process cannot be identified holds a slot forever. That happens when the owner crashed between start and record, with no wrapper pid file.
- **Needed.** An explicit operator action, MCP or CLI, to inspect and clear such a hold, with a confirmation step.
